# Юрко

Сайт юридичної допомоги. Головний напрям — кредити військовим (п. 15 ст. 14 Закону про соцзахист військовослужбовців: без відсотків, пені і штрафів); комуналка — додатковий. Для кожного: безкоштовна перевірка (квіз), три пакети послуг, магазин шаблонів з оплатою через WayForPay, заявки в Telegram.

## Структура

```
index.html            головна: кредити військовим + квіз «Скільки з вас вимагають зайвого?» (assets/vijsk.js)
komunalka.html        комуналка + квіз «Чи можуть з вас це стягнути?»
poslugy.html          пакети: військовим (Сам / Під ключ / Суд) і комуналка (Самозахист / Перевірка / Суд)
magazyn.html          шаблони документів
oferta.html           оферта і політика конфіденційності (заповнити реквізити ФОП)
assets/
  style.css           дизайн (світла і темна тема)
  davnist.js          розрахунок давності, строку на скасування наказу, пені
  app.js              квіз комуналки, форма заявки, кнопки оплати
  vijsk.js            квіз для військових, форма заявки з кодом від побратима (?ref=КОД у посиланні підставляє код)
netlify/functions/
  _lib.js             каталог продуктів і цін, підписи WayForPay, Telegram, email
  pay.js              створює підписаний платіж
  wfp-callback.js     приймає підтвердження оплати, шле email і сповіщення
  return.js           сторінка «Дякуємо» з посиланнями на файли
  download.js         віддає файл за підписаним посиланням
  lead.js             заявка з квізу → Telegram
  templates/          сюди кладемо .docx і .pdf шаблони (не публікуються напряму)
```

Ціни змінюються в двох місцях: `netlify/functions/_lib.js` (те, що реально списується) і текст на сторінках.

## Змінні середовища (Netlify → Site settings → Environment variables)

| Змінна | Що це |
|---|---|
| `SITE_URL` | `https://ваш-домен` без слеша в кінці |
| `WFP_MERCHANT` | Merchant login з кабінету WayForPay |
| `WFP_SECRET_KEY` | Merchant secret key |
| `WFP_DOMAIN` | домен, зареєстрований у WayForPay (якщо відрізняється від SITE_URL) |
| `DOWNLOAD_SECRET` | будь-який довгий випадковий рядок |
| `TG_BOT_TOKEN` | токен бота від @BotFather |
| `TG_CHAT_ID` | ваш chat id (напишіть боту, потім відкрийте `https://api.telegram.org/bot<TOKEN>/getUpdates`) |
| `RESEND_API_KEY` | ключ resend.com для листів з посиланнями (необовʼязково) |
| `EMAIL_FROM` | напр. `Юрко <hello@ваш-домен>` |

## Деплой

1. Запушити репозиторій на GitHub.
2. Netlify → Add new site → Import from GitHub → вибрати репозиторій. Build command порожній, publish directory `.`.
3. Додати змінні середовища з таблиці вище, натиснути Redeploy.
4. У кабінеті WayForPay додати домен сайту.
5. Покласти файли шаблонів у `netlify/functions/templates/` з іменами з `_lib.js`.
6. Перевірити: пройти квіз і надіслати заявку (має прийти в Telegram), купити найдешевший шаблон за 149 грн.

## Реклама

Перед запуском вставити в `<head>` кожної сторінки Meta Pixel і Google tag. `app.js` уже шле події `QuizAnswer`, `QuizComplete`, `Lead`, `InitiateCheckout`. UTM-мітки з посилання потрапляють у заявку в Telegram.

## Правова модель розрахунку

Див. коментар у `assets/davnist.js`. Ключові дати: пауза давності 02.04.2020 – 03.09.2025, поновлення з 04.09.2025 (Закон № 4434-IX), заборона пені для населення з 24.02.2022. Перевіряти актуальність після змін законодавства.

## Шаблони для військових

`node tools/templates/build-vijsk.js` (потрібен пакет `docx`), потім `soffice --headless --convert-to pdf instrukciya-vijsk.docx` у `netlify/functions/templates/`.
Правова основа і позиції ВС — у коментарях `tools/templates/build-vijsk.js` і `assets/vijsk.js`. Перевіряти після змін законодавства.

## «Приведи побратима»

Код вигляду `ЮРКО-ІМʼЯ` видається клієнту вручну після результату. Посилання `https://askyurko.com.ua/?ref=ЮРКО-ІМʼЯ` підставляє код у форму. Код приходить у заявці в Telegram; облік — у таблиці (хто привів, оплатив, бонус).
